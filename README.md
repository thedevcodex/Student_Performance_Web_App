# Student Performance Prediction 🎓

A simple **Student Performance Prediction** web app built using **Artificial Neural Network (ANN)**.

## 🛠️ Technologies

* Python
* TensorFlow / Keras
* Scikit-learn
* Pandas
* NumPy
* Streamlit

## 📁 Project Structure

```text
app.py
student_performance_ann.ipynb
student_performance_model.keras
scaler.pkl
requirements.txt
dataset
```

## 🚀 Run the App

```bash
pip install -r requirements.txt
streamlit run app.py
```
